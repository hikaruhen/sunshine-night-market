## 獨立審查發現與修正

原題標示「可常溫保存」，卻讓玩家在「放冰箱／放常溫架」之間選擇；可常溫保存不代表不能冷藏，因此會把安全合理的放置選擇誤當科學錯誤。問題成立，前次自測未發現這個語意漏洞，不能據前次 100 分流程宣稱已通過科學驗收。

本輪食品任務改為「依上述條件，是否必須冷藏？」；所有五題使用「必須冷藏／可常溫保存」，回答的是冷藏必要性，不是實際放置地點。

- 教學、主題提示、每題問題、兩個按鈕、預設回饋及錯誤解析全部同步。
- 未開封保久乳與乾香菇均表達「不必冷藏」不等於「禁止冷藏」。
- 已開封保久乳、泡發香菇、切片西瓜按明示情境需冷藏；不因產品品名概括所有狀態。
- 成功圖像改為原地確認效果，不再飛向指定儲存位置，避免動畫繼續暗示兩個地點互斥。
- GAME_SPEC.md、README、驗收、計畫、科學來源文件同步；舊報告存於 docs/TEST_REPORT_V6.1_BEFORE_FOOD_CLARIFICATION.md，不能取代本輪驗證。
